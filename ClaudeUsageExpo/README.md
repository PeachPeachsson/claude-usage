# Claude Usage

En enkel Expo-app för att visa Claude- och Codex-användning.

## Installera och starta

Kräver [Node.js](https://nodejs.org/) och [Expo Go](https://expo.dev/go).

```bash
cd ClaudeUsageExpo
npm install
npx expo start
```

Skanna QR-koden med iPhone-kameran och öppna appen i Expo Go.
